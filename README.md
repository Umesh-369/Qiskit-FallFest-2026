# Qiskit Fall Fest 2026 ⚛️

Solutions to the four Qiskit Fall Fest challenges, exploring quantum gates, measurement probabilities, and qubit correlations using Python and Qiskit.

## Challenges

- **Challenge 1:** Predict the Output
- **Challenge 2:** Make the Quantum Coin Biased
- **Challenge 3:** Can You Change the Correlation?
- **Challenge 4:** Quantum Correlation Switch

## Run the Notebooks

Open a notebook in [Google Colab](https://colab.research.google.com/) or run it locally with Jupyter Notebook. Install the required Qiskit packages when prompted.

## Tech Stack

- Python
- Qiskit
- Qiskit Aer
- Matplotlib
